# Birecik Restaurant Website

Bu proje, Birecik Restaurant için oluşturulmuş modern ve interaktif bir web sitesidir.

## Özellikler

- Ana sayfa
- Menü sayfası
- Değerlendirme sayfası
- Animasyonlu geçişler
- Pul biber efekti
- Responsive tasarım

## Kurulum

1. Tüm dosyaları bir klasöre indirin
2. `index.html` dosyasını bir web tarayıcısında açın

## Gereksinimler

- Modern bir web tarayıcısı (Chrome, Firefox, Safari, Edge)
- JavaScript desteği

## Dosya Yapısı

```
birecik-restaurant/
├── index.html          # Ana sayfa
├── menu.html           # Menü sayfası
├── rate.html           # Değerlendirme sayfası
├── styles.css          # Stil dosyası
├── script.js           # JavaScript dosyası
└── images/             # Resimler klasörü
```

## Geliştirme

Web sitesini geliştirmek için:

1. HTML dosyalarını düzenleyin
2. CSS stillerini `styles.css` dosyasında değiştirin
3. JavaScript kodunu `script.js` dosyasında güncelleyin
4. Yeni resimler eklemek için `images` klasörünü kullanın
